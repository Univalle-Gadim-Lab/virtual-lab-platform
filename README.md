# Virtual Lab Platform

Plataforma web para la gestión remota y virtualización segura de recursos computacionales mediante
contenedores.

## Arquitectura

Monolito modular construido con:

- Java 21
- Spring Boot 4.0.x
- Gradle 9.3.1
- Kotlin DSL

## Módulos

- virtual-lab-platform-boot
- virtual-lab-platform-users
- virtual-lab-platform-instances
- virtual-lab-platform-security
